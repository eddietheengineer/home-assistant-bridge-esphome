# ha_discovery_config

## Purpose

Known string-valued ERD IDs for the MQTT adapter. The MQTT adapter publishes these ERDs as text (decoded ASCII) rather than hex.

## Contents

A static array of ERD IDs (`ha_string_erd_ids[]`) with a count (`ha_string_erd_count`). Each ERD in this list is published as a null-terminated ASCII string to MQTT, rather than as a hex-encoded payload.

## Generation

This file is generated by `scripts/generate_erd_lists.py` from the GE Appliances Public API Documentation. Do not edit manually.

## Dependencies

- `stdint.h` — `uint16_t` type

## Key Design Decisions

- **Generated, not hand-written**: The list is derived from the appliance API documentation, ensuring it stays in sync with the official ERD definitions.
- **Used by MQTT adapter**: The `EsphomeMqttClientAdapter` checks this list when publishing ERD values — if the ERD is in the list, the value is published as decoded ASCII text; otherwise, it's published as hex.
