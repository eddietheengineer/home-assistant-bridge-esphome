# DeviceIdentityManager

## Purpose

Reads appliance identity ERDs (type, model number, serial number) and assembles a unique MQTT-topic-safe device identifier string. If a `device_id` is pre-configured in YAML, the read sequence is still completed but at the end the preconfigured value will be used..

## Public API

| Method | Description |
|--------|-------------|
| `init(configured_id, erd_client, host_address)` | Initialize with optional pre-configured ID, ERD client, and host address |
| `on_erd_read_completed(erd, data, size)` | Called when an ERD read succeeds |
| `on_erd_read_failed(erd)` | Called when an ERD read fails |
| `get_state()` | Returns the current `DeviceIdState` |
| `get_device_id()` | Returns the final device ID string (preconfigured or autogenerated) |
| `get_model_number()` | Returns the model number string (used by HA discovery manager) |
| `get_serial_number()` | Returns the serial number string (used by HA discovery manager) |

## State Machine

```
DEVICE_ID_STATE_READING_APPLIANCE_TYPE  (ERD 0x0008)
  └─ read failed → retry appliance type
  └─ read completed → DEVICE_ID_STATE_READING_MODEL_NUMBER

DEVICE_ID_STATE_READING_MODEL_NUMBER    (ERD 0x0001)
  └─ read failed → retry model number
  └─ read completed → DEVICE_ID_STATE_READING_SERIAL_NUMBER

DEVICE_ID_STATE_READING_SERIAL_NUMBER   (ERD 0x0002)
  └─ read failed → retry serial number
  └─ read completed → assemble generated ID → DEVICE_ID_STATE_COMPLETE

DEVICE_ID_STATE_COMPLETE
  └─ get_device_id() returns final device ID string (preconfigured string or autogenerated one)
  └─ All actions complete

```
Device ID format: `{appliance_type_string}_{sanitized_model}_{sanitized_serial}`

## Dependencies

- `tiny_gea3_erd_client` — ERD client interface (used for both GEA3 and GEA2 via adapter)
- `appliance_type_to_string()` — generated function that maps appliance type byte to string
- `geappliances_bridge_constants.h` — ERD constants

## Key Design Decisions

- **Always Reads Erds**: Even with a preconfigured device ID, all steps will be the same except for the final get_device_id() gets either populated based on the autogenerated or preconfigured ID
- **MQTT topic sanitization**: Characters `+`, `#`, `/`, `$`, spaces, and non-printable bytes are replaced with `_` to ensure the device ID is safe for MQTT topics.

## Testing

Covered by unit tests in `test/tests/device_identity_manager_test.cpp` (30 tests) and HSM integration tests in `test/tests/startup_hsm_test.cpp`. The self-driving retry logic is tested via simulated ERD read failures.
